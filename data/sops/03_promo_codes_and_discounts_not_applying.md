# Promo Codes and Discounts Not Applying

## Purpose
This document outlines the standard operating procedure for handling customer inquiries regarding promo codes that fail to apply, appear invalid, or cannot be combined during the checkout process on the Brightcart website.

## When this applies
This procedure applies when a customer contacts support via the web form, email, or live chat claiming a discount code is not working. It covers issues involving expired codes, attempts to stack multiple codes, and potential technical errors within the Brightcart checkout system.

## Steps for the agent
1. **Verify the code:** Ask the customer for the specific promo code and check its status in the internal database. 
2. **Check Policy Constraints:** Confirm if the customer is attempting to use more than one code. Brightcart policy strictly allows only one code per order.
3. **Check Expiration:** Verify the expiry date of the code. If the code is expired, it cannot be reapplied under any circumstances.
4. **Investigate Technical Faults:** If the code is active and meets all criteria but still fails, check the system logs to determine if a technical fault occurred.
5. **Request Approval:** If you confirm a system fault prevented the code from applying, escalate the ticket to a Team Lead. Only a Team Lead has the authorization to manually honor a code that failed due to a technical error.
6. **Provide Resolution:** Communicate the findings clearly to the customer. If the code was expired or invalid, explain the terms of the specific promotion.

## What to tell the customer
"I have investigated your promo code and found that it is currently expired and therefore cannot be applied to your order. Please note that our system only accepts one promo code per transaction, and they cannot be combined with other offers. If you believe this is a technical error, please provide a screenshot of the checkout page so I can look into this further for you."

## Escalation and priority
*   **Low:** General questions about how to use a code or where to find active promotions.
*   **Medium:** A customer reports a code is not working, but they are still able to complete their purchase at full price.
*   **High:** The customer is unable to complete a purchase specifically because they are waiting for a promised discount to apply.
*   **Urgent:** If more than three customers report the same promo code failure within 30 minutes, treat this as a possible website outage. Mark the ticket as Urgent and notify the Engineering on-call team immediately.

## Common mistakes
*   **Over-promising:** Never manually apply a discount or promise a refund for a missed promo code without explicit Team Lead approval.
*   **Ignoring stacking rules:** Failing to inform the customer that Brightcart only allows one code per order, leading to repeated failed attempts.
*   **Misclassifying Outages:** Treating a systemic failure as an individual user error instead of reporting it as a potential outage.
*   **Ignoring Expiration:** Manually honoring expired codes, which violates company policy.
